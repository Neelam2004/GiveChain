# GiveChain 🌍

GiveChain ek web platform hai jo social causes ko promote aur support karta hai through transparent donations. Isme HTML, CSS, JavaScript aur backend integration ka use hua hai.

---

## 🚀 Project Setup & Run Instructions

### 🔧 Requirements

- Node.js (v14 ya upar)
- npm ya yarn
- MongoDB (agar backend me database use ho raha ho)
- Live Server (optional frontend testing ke liye)

### 📦 Installation

1. **Repo clone karo:**

```bash
git clone https://github.com/Neelam2004/GiveChain.git
cd GiveChain
```

2. **Dependencies install karo:**

```bash
npm install
```

3. **Frontend run karne ke liye:**

`index.html` ko browser me open karo ya VS Code ka Live Server extension use karo.

4. **Backend run karne ke liye:**

```bash
cd backend
npm install
npm start
```
